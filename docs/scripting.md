# 🐍 Python Scripting & API

RayMol is built on PyMOL 3.x and supports standard PyMOL commands via its internal Python 3.13 console.

### Running Scripts

You can run standard `.pml` or `.py` scripts by dragging them into the RayMol window or using the `run` command in the console.

### Key API Differences

While most commands are identical to Open-Source PyMOL, RayMol optimizes rendering commands for the Metal engine.
