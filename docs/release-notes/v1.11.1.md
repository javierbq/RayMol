## RayMol 1.11.1

A rendering fix for sticks after using Move mode.

- **Fixed: opening Move mode washed out every stick in the session.** The Move
  gizmo's cylinders latched their cap style and color blending onto every
  cylinder drawn afterwards, so bonds picked up flat, notched ends and a
  full-length color ramp instead of the hard color change at the middle of
  the bond. It affected every object, every representation and every frame from
  that point on, and deleting the gizmo did not undo it. The effect grew with
  `stick_radius`, so it was most obvious on thicker sticks. Cap style and
  coloring are now carried per cylinder, and sticks render the same whether or
  not Move mode has been opened.

Built on the open-source PyMOL engine. Updates install automatically via the in-app updater (**Check for Updates…** in the app menu).
