## RayMol 1.10.1

A fix for a frozen viewport when you open a session by double-clicking it.

- **Fixed: opening a `.pse` from Finder could leave the 3D view frozen.** When
  a double-click (or `open file.pse`) *launched* RayMol, the structure appeared
  but the viewport stopped redrawing: dragging didn't rotate anything and the
  app felt sluggish, while menus, panels and the command line stayed
  responsive. Opening the same file into an already-running RayMol was
  unaffected. The viewport now drives its own render loop, so it starts
  reliably however the app was launched — and a still scene costs no more to
  display than it did before.

Built on the open-source PyMOL engine. Updates install automatically via the in-app updater (**Check for Updates…** in the app menu).
