## RayMol 1.12.1

A bugfix release addressing selection and hover behavior in sessions with grouped objects.

- **Group picking and hover (#748):** Fixed an issue where atoms in objects hidden by a disabled group could still be hovered and clicked in the viewport. `metal_pick` and grid mode now respect group visibility hierarchies so disabled group members cannot be clicked or receive grid slots.
- **Sequence panel (#748):** Sequence viewer rows are now properly hidden when parent groups are disabled.
