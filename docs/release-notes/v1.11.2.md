## RayMol 1.11.2

A rendering fix for the `lines` representation with more than one object on screen.

- **Fixed: only one object's lines were drawn when two or more objects showed
  lines.** Loading two structures and choosing *show ▸ lines* on **all** drew the
  lines of the last object only; the others' lines were missing, and they came
  back the moment you toggled that object off. Every line-drawing object shared a
  single GPU vertex buffer, so whichever object was drawn last overwrote the
  others' geometry before the frame reached the GPU. Each object now draws from
  its own buffer. Sticks were never affected — only lines. The label leader lines
  drawn beside offset labels shared the same flaw and are fixed with it.

Built on the open-source PyMOL engine. Updates install automatically via the in-app updater (**Check for Updates…** in the app menu).
