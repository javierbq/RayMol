# 🤖 AI & MCP Integration

RayMol includes a native **Model Context Protocol (MCP)** server, allowing you to drive the application using natural language via **Claude**.

## Setup

1. **Use the Direct Version:** Ensure you are using the Homebrew or Direct Download version (App Store version does not support MCP).
2. **Enable Server:** In RayMol, go to **Connect > Connect an AI app...**
3. **Claude Desktop:** Open your Claude app. It will detect the RayMol server automatically.

## Example Prompts

- "Load 1L2Y and show it as a green cartoon."
- "Find the distance between the ligand and the active site residues."
