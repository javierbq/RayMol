# 🧬 RayMol Documentation

Welcome to the official wiki for **RayMol**, the high-performance molecular visualization suite built natively for Apple Silicon.

RayMol combines the industry-standard power of PyMOL with modern Metal-accelerated rendering, offering a seamless experience across macOS, iPad, and iPhone.
