## Key Features

<CardGrid stagger>
  <Card title="Metal Real-Time Rendering" icon="rocket">
    Hardware ray-traced ambient occlusion and shadows, order-independent weighted-blended transparency, and Metal-accelerated viewport rendering on Apple Silicon.
    <a class="card-link" href="/RayMol/guides/rendering-export/">Rendering & Export →</a>
  </Card>
  <Card title="Studio Lights & Materials" icon="sun">
    Configurable multi-light rigs with interactive directional controls, environment lighting, and physically inspired materials like Matte, Plastic, Metallic, Glass, and Marble.
    <a class="card-link" href="/RayMol/guides/lighting/">Studio Lights →</a>
  </Card>
  <Card title="Structure Prediction & Design" icon="puzzle">
    Run state-of-the-art ML models on-device with MLX, including Boltz-2 and (on macOS) Protenix structure prediction, alongside ProteinMPNN sequence design.
    <a class="card-link" href="/RayMol/guides/predict/">Structure Prediction →</a>
  </Card>
  <Card title="PyMOL Engine & Python" icon="document">
    The genuine open-source PyMOL core with an embedded Python 3.13 runtime, PyMOL `.pse` sessions, and familiar command syntax.
    <a class="card-link" href="/RayMol/reference/commands/">Commands & Python API →</a>
  </Card>
  <Card title="AI Control via MCP" icon="setting">
    A built-in Model Context Protocol server connects AI assistants directly to RayMol to inspect molecular scenes, select residues, and execute commands. Available in the direct-download macOS build (Homebrew/DMG).
    <a class="card-link" href="/RayMol/guides/mcp-setup/">MCP setup →</a>
  </Card>
  <Card title="Analysis Notes & Glycobiology" icon="pencil">
    Document observations with 3D camera and scene links, inline #tags, and live residue/contact/measurement inserts, alongside native SNFG 3D glycan symbols and topology analysis.
    <a class="card-link" href="/RayMol/guides/analysis-notes/">Analysis Notes →</a>
  </Card>
  <Card title="Native Across Apple Platforms" icon="laptop">
    A unified SwiftUI and Metal interface tailored for macOS desktop workflows, iPad touch interaction, and iPhone inspection on the go.
    <a class="card-link" href="/RayMol/getting-started/installation/">Installation →</a>
  </Card>
</CardGrid>
