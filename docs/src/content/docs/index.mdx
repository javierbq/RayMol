## Key Features

<CardGrid stagger>
  <Card title="Metal Real-Time Rendering" icon="rocket">
    Hardware ray-traced ambient occlusion and shadows, weighted-blended transparency, and real-time shadow mapping on supported Apple Silicon devices.
  </Card>
  <Card title="Built on PyMOL" icon="document">
    The genuine open-source PyMOL core, an embedded Python 3.13 runtime, and native `.pse` session support in a modern Apple-platform interface.
  </Card>
  <Card title="Built-in MCP Server" icon="setting">
    Direct Model Context Protocol integration lets supported AI apps inspect and manipulate molecular scenes through explicit tool calls.
  </Card>
  <Card title="Native Across Apple Platforms" icon="laptop">
    A shared SwiftUI and Metal codebase designed for macOS, iPad, and iPhone.
  </Card>
</CardGrid>
